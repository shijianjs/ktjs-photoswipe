<ktjs-features section-title="为什么用 Kotlin 写前端动画" tinted>

<ktjs-feature icon="lucide:images" title="两个模块都封装">灯箱、核心画廊，以及两者共同继承的事件/过滤器层都是带类型的，包括滚动平移与缩放 API。</ktjs-feature>

<ktjs-feature icon="lucide:list-checks" title="带类型的选项">`photoSwipeOptions { … }` 是接口，覆盖上游全部约 60 个选项，拼错就是编译错误。</ktjs-feature>

<ktjs-feature icon="lucide:puzzle" title="核心模块交接已内置">`photoSwipeModuleLoader()` 提供灯箱需要的 `pswpModule`；没有它，上游在第一次点击时就会抛错。</ktjs-feature>

<ktjs-feature icon="lucide:flask-conical" title="在 Chromium 里测试">模块测试挂载真实画廊并读回条目数据；演示页的 Playwright 套件会打开灯箱并按 Escape 关闭。</ktjs-feature>

<ktjs-feature icon="lucide:book-open" title="双语文档">每个页面都有英文与简体中文两版，结构一致，并各自跳转到演示页与 Dokka API 文档。</ktjs-feature>

</ktjs-features>
