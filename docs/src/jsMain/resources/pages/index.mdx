<ktjs-features section-title="Why write animations in Kotlin" tinted>

<ktjs-feature icon="lucide:images" title="Both modules, fully wrapped">The lightbox, the core gallery and the event/filter layer both extend are all typed, including the scroll-pan and zoom API.</ktjs-feature>

<ktjs-feature icon="lucide:list-checks" title="Typed options">`photoSwipeOptions { … }` is an interface with all ~60 upstream options, so a misspelled one is a compile error.</ktjs-feature>

<ktjs-feature icon="lucide:puzzle" title="The core module hand-off is built in">`photoSwipeModuleLoader()` supplies the `pswpModule` the lightbox needs; without it upstream throws at the first click.</ktjs-feature>

<ktjs-feature icon="lucide:flask-conical" title="Tested in Chromium">The module's tests mount real galleries and read item data back; the demo's Playwright suite opens the lightbox and presses Escape.</ktjs-feature>

<ktjs-feature icon="lucide:book-open" title="Docs in two languages">Every page exists in English and Simplified Chinese, with the same structure, and links out to the demo and the Dokka reference.</ktjs-feature>

</ktjs-features>
